Agent Lee is now available to a broader set of Cloudflare accounts.

### What changed

- **Free plans** — continue to have full access to Agent Lee.
- **Self-serve paid plans** — Agent Lee is now enabled for Pro and Business accounts.

Agent Lee remains in beta. Features and behaviors may change as the product evolves.
